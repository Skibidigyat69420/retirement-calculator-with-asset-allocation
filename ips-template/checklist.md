# IPS Preparation Checklist

Use this checklist to ensure every CFAI-required element is addressed before signing the IPS.

## Client Discovery
- [ ] Personal / entity identification verified
- [ ] Family composition and dependents documented
- [ ] Sources of wealth and income captured
- [ ] Net worth and liabilities estimated
- [ ] Cash-flow projections prepared
- [ ] Existing holdings listed and categorized
- [ ] Investment experience and literacy assessed
- [ ] Risk tolerance questionnaire completed
- [ ] Behavioral finance observations noted

## Objectives
- [ ] Return objective stated in nominal and real terms
- [ ] Required return linked to specific goals
- [ ] Risk tolerance classified
- [ ] Risk capacity distinguished from risk willingness
- [ ] Maximum drawdown and volatility limits set

## Constraints (LLLRTU)
- [ ] **Liquidity:** Emergency reserve and near-term cash needs identified
- [ ] **Time Horizon:** Single or multi-stage horizon defined
- [ ] **Tax:** Tax status, rates, and sensitive strategies documented
- [ ] **Legal / Regulatory:** SEBI / other framework and restrictions noted
- [ ] **Unique Circumstances:** Concentrated holdings, family dynamics, ESG, health, etc.

## Strategy & Implementation
- [ ] Permitted and prohibited investments listed
- [ ] Strategic asset allocation table completed
- [ ] Tactical allocation limits defined (if any)
- [ ] Single-security / sector / geography limits set
- [ ] Derivatives and leverage policy stated
- [ ] ESG / SRI policy included (if applicable)

## Governance
- [ ] Rebalancing method and thresholds defined
- [ ] Benchmark(s) selected
- [ ] Reporting frequency and content specified
- [ ] Review triggers listed
- [ ] Roles and responsibilities assigned
- [ ] Fee structure and compensation disclosed

## Documentation
- [ ] IPS drafted using `CFA_IPS_Template.md`
- [ ] Appendices attached (risk profile, cash flows, holdings)
- [ ] Client reviewed and acknowledged
- [ ] Advisor signed
- [ ] Date and next review date recorded
- [ ] Copy provided to client
